# Enterprise Asset Management (EAM) API

RESTful API for managing corporate IT assets (computers, licenses, employees, and incidents).

## Tech Stack
- **Language:** Java 17+
- **Framework:** Spring Boot 3.x (Spring Security, Spring Data JPA)
- **Database:** PostgreSQL
- **Authentication:** JWT (JSON Web Tokens)
- **Documentation:** Swagger / OpenAPI
- **Containerization:** Docker & Docker Compose
